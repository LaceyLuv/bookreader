글결 단축키 안내
==================

1. 단축키 켜기/끄기

- 설정의 "키보드 단축키 사용" 옵션에서 글결의 단축키를 한번에 켜거나 끌 수 있습니다.
- 단축키를 끄면 페이지 이동키를 포함한 앱 전용 단축키가 작동하지 않습니다.
- Tab, Shift+Tab, Enter 및 대화상자를 닫는 Esc 같은 기본 키보드 접근성 조작은 계속 사용할 수 있습니다.
- 입력창·검색창·설정창에 글자를 입력하거나 한글을 조합하는 동안에는 읽기 단축키가 작동하지 않습니다.

2. 전체 및 창 표시

F11                  전체화면 전환
Shift+F11            Windows 제목 표시줄 표시/숨기기
Ctrl+H               하단 진행률·조절바 표시/숨기기
Ctrl+, (Ctrl+Comma)  현재 화면의 설정 열기/닫기

※ Ctrl+,는 검색·주석·인코딩·책 정보 같은 다른 패널이나 대화상자가 열려 있지 않을 때 작동합니다.

3. 리더 공통

←, ↑, Page Up, Shift+Space   이전 페이지
→, ↓, Page Down, Space       다음 페이지
Home                            첫 페이지
End                             마지막 페이지
Alt+Left                        서재로 돌아가기
B                               현재 페이지 북마크
Shift+B                         ZIP 북마크 줄 표시/숨기기
L                               한 페이지/두 페이지 레이아웃 전환
[                               글자 또는 이미지 크기 줄이기
]                               글자 또는 이미지 크기 늘리기

※ B, L, [, ] 같은 한 글자 단축키는 리더 화면에서 입력창·버튼을 편집하거나 조작 중이지 않을 때 작동합니다.

4. 파일 형식별

T       EPUB 목차 표시/숨기기
M       TXT·EPUB 메모/주석 패널 열기
Ctrl+F  TXT·EPUB 검색 열기
Shift+B ZIP 북마크 줄 표시/숨기기

5. 서재

Ctrl+O               책 파일 열기
Ctrl+F               서재 검색
Ctrl+, (Ctrl+Comma)  서재 설정 열기/닫기
Ctrl+A               서재 목록에 초점이 있을 때 현재 표시된 책 전체 선택

※ 삭제, 백업 복원, 설정 초기화 같이 데이터에 영향을 주는 기능에는 직접 단축키가 없습니다.
